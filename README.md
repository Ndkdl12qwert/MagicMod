# BlackGold Mod

## 📖 关于这个模组

**BlackGold Mod** 是一个为 **Minecraft 1.20.1** 设计的 **Forge** 模组，它为游戏添加了一套完整的黑金装备体系。

## ✨ 当前版本特性 (v1.0.0)

### 🏭 黑金装备生产链

一条完整的黑金装备升级路线，从下界合金开始，经过高炉、工作台与锻造台，一步步打造成黑金套装。

| 阶段 | 操作 | 产物 |
| :--- | :--- | :--- |
| 1 | 将 **下界合金块** 放入 **高炉** 烧炼 (15秒) | 获得 **黑金粒** |
| 2 | 用 **1个金块** 和 **8个黑金粒** 在工作台合成 | 获得 **黑金锭** |
| 3 | 用 **下界合金升级模板** 和 **8个黑金锭** 合成 | 获得 **神明黑金升级模板** |
| 4 | 在 **锻造台** 中，用下界合金装备 + 黑金锭 + 神明黑金升级模板 | 获得 **黑金装备** |

### 🗡️ 黑金剑 (GODSWORD)

这是一把打破规则的神器，持有它便等于拥有神权：

*   **左键**：直接抹除任何实体（无视血量与护甲）
*   **右键**：释放当前选中的“神权”技能
*   **Shift + 右键**：在四种神权模式之间切换
*   **手持时自动开启飞行**：放下即关闭，无需按键
*   **附魔光效**：永远闪烁，永不磨损

#### ⚡ 四种神权技能

| 技能 | 效果 |
| :--- | :--- |
| **⚡天罚** | 在玩家周围 128 格内，对所有非玩家实体降下闪电并将其抹除 |
| **🔥焚世** | 在玩家周围 128 格内，将所有非玩家实体点燃并抹除 |
| **❄️永冻** | 在玩家周围 128 格内，将所有非玩家实体冻结并抹除 |
| **🌪️风暴** | 在玩家周围 128 格内，将所有非玩家实体卷飞并抹除 |

### 🛡️ 黑金盔甲

*   **套装效果**：
    *   **2件**：速度提升
    *   **3件**：伤害吸收
    *   **全套**：伤害提升、抗性提升、生命恢复、夜视、水下呼吸、防火
*   **全套效果**：穿上全套黑金盔甲后，玩家将获得 **完全无敌** 状态：
    *   免疫所有形式的伤害
    *   免疫 `/kill` 指令
    *   免疫所有负面效果（凋零、中毒等）
    *   保持满饱食度

### 🛡️ 防 /kill 机制

手持黑金剑或穿着全套黑金盔甲时，玩家会进入“真无敌”状态，`/kill` 指令无法将其移除。

## 🎮 使用说明

1.  从 **下界** 获取下界合金块。
2.  用高炉烧炼下界合金块，获得黑金粒。
3.  合成黑金锭和神明黑金升级模板。
4.  在锻造台上将你的下界合金装备升级为黑金装备。
5.  手持黑金剑，体验神权的力量。

## 📦 下载与安装

### 🧩 依赖
*   **Minecraft**: 1.20.1
*   **模组加载器**: Forge 47.4.10+

### 🔗 下载地址
*   [Modrinth 项目页面](https://modrinth.com/mod/magicmodalpha)

### 🚀 安装步骤
1.  下载适用于 Minecraft 1.20.1 的 Forge 安装器。
2.  安装 Forge 客户端。
3.  将本模组的 `.jar` 文件放入游戏目录的 `mods` 文件夹中。
4.  启动游戏即可。

## 🛠️ 开发与构建

本模组使用 Forge MDK 和 Gradle 构建。

1.  克隆仓库：
    ```bash
    git clone https://github.com/Ndkdl12qwert/BlackGoldMod.git
    ```
2.  进入项目目录并构建：
    ```bash
    cd BlackGoldMod
    gradlew clean build
    ```
3.  构建产物位于 `build/libs/` 目录下。
